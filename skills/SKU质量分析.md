# SKU质量分析

## 元信息
- **版本**: 1.1
- **创建时间**: 2026-04-09
- **最后更新**: 2026-04-16
- **触发条件**: 用户提到质量情况、质量怎么样、质量分析、产品质量、SKU质量

## 描述
对指定SKU产品进行整体质量分析，展示生产、出货、客退综合指标和月度趋势。注意：这不是客退分析，而是更全面的质量评估。

## 与客退分析的区别（重要）
- **本 Skill**：查 `sku_quality` + `sku_quality_monthly`，展示生产直通率、出货合格率、退货率等综合指标
- **客退分析 Skill**：查 `return_overview` 等 7 个客退维度工具，专注退货原因、不良物料、责任归属等
- 用户问"XX质量情况/质量怎么样" → 用本 Skill
- 用户问"XX客退分析/退货分析" → 用客退分析 Skill

## 知识
- SKU 是产品型号的唯一标识
- `sku_quality` 表包含综合质量指标：生产数量、直通率、出货数量、OQC不良率、客退数量、退货率等
- `sku_quality_monthly` 表包含月度趋势数据，可看各指标的变化走向
- 退货率基线因产品类别不同：空气净化器≤2%、新风机≤1.5%、扫地机器人≤3%
- 新品上市初期退货率偏高属正常现象，需区分质量退货和非质量退货

## 流程
1. 调用 `sku_overview` 工具获取 SKU 的整体质量数据（sku_quality）和月度趋势（sku_quality_monthly）
2. 分析整体质量指标是否达标（与基线对比）
3. 分析月度趋势，判断质量走向（改善/恶化/稳定/波动）
4. 读取 knowledge/质量基线标准.md 进行基线对比
5. 给出综合评价和改善建议

## 输出格式
### 整体质量指标
用表格展示 SKU 的关键质量指标（如生产数量、直通率、出货数量、OQC不良率、客退数量、退货率等），并标注与基线的对比结果（正常/预警/严重）。

### 月度趋势
用表格或描述展示近几个月的关键指标变化趋势，判断是改善、恶化、波动还是稳定。

### 综合评价与建议
基于指标和趋势给出评价，提出改善建议。
