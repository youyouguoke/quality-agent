# 客退多维度分析报告

## 元信息
- **版本**: 1.1
- **创建时间**: 2026-04-09
- **最后更新**: 2026-04-13
- **触发条件**: 用户问客退分析、退货分析、客退报告、退货报告、客退概况

## 描述
对客退机数据进行7个维度的结构化分析，生成完整的客退分析报告。

## 知识
- 复测完成率 = 已复测+待翻新+已翻新+已完成的数量 / 退货总数
- 返修完成率 = 已翻新+已完成的数量 / 退货总数
- 受理原因分为四大类：质量（平台商-质量、三包期内换货、产品质量问题、维修、多维换货、开箱损、平台商-质量换货）、7无（7天无理由、平台商-七无）、付费换新（平台商-付费换新）、其他
- 不良原因和不良物料字段可能包含多个值（逗号分隔），数据已做多值拆分统计
- 空值已在统计时排除，仅统计有复测结果的记录
- **NTF数据排除规则**：复测结果为"复测OK"或"使用痕迹"的记录视为NTF。**分析责任归属和不良物料时，必须排除NTF数据**（复测结果≠"复测OK"且≠"使用痕迹"），只分析确认有故障的记录才有意义

## 流程
**精准回答原则**：用户只问某个维度时，只调用对应的工具，只输出该维度的分析。只有用户明确要求"全面分析"或"客退报告"时才输出完整报告。

**客退数据按维度独立查询**，每个 MCP 工具对应一个分析维度：
- 问"处理状况" → 只调 `get_state_analysis` → 只输出处理状况分析
- 问"受理原因" → 只调 `get_accept_reason_analysis` → 只输出受理原因分析
- 问"不良原因" → 只调 `get_defect_cause_analysis` → 只输出不良原因分析
- 问"不良物料" → 只调 `get_defect_material_analysis` → 只输出不良物料分析
- 问"复测结果" → 只调 `get_retest_result_analysis` → 只输出复测结果分析
- 问"责任归属" → 只调 `get_responsibility_analysis` → 只输出责任归属分析
- 问"整体概况" → 只调 `get_return_overview` → 只输出整体概况
- 问"全面分析/客退报告" → 调全部工具，输出完整报告

**单维度输出时，标题不要带编号**（如直接写"处理状况分析"，不要写"七、处理状况分析"）。编号仅在全量报告中使用。

## 输出格式
### 一、整体概况
用表格展示：产品名称、生产工厂、维修工厂、退货数量、复测完成率、返修完成率

### 二、受理原因分析
数据已按四分类（质量、7无、付费换新、其他）汇总好，用表格展示各分类的数量和占比，并展示每个分类下的明细原因。

### 三、复测结果分析
数据仅包含有复测结果的记录（排除未复测的），展示TOP5复测结果的数量和占比，其余归入"其他"。

### 四、不良原因分析
仅统计有复测结果的记录。展示TOP5不良原因的数量和占比，其余归入"其他"。注意数据已做多值拆分统计。空值已排除。

### 五、不良物料分析
仅统计有复测结果的记录。展示TOP5不良物料的数量和占比，其余归入"其他"。注意数据已做多值拆分统计。空值已排除。

### 六、责任归属分析
仅统计有复测结果的记录。展示TOP10责任归属的数量和占比，其余归入"其他"。注意数据已做多值拆分统计。

### 七、处理状况分析
用表格展示各状态的数量和占比。

### 八、核心结论与建议
（仅全量分析时输出）基于以上7个维度的数据，总结3-5条核心发现和改善建议。
