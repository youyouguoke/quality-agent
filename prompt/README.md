# 质量管理 AI Agent — 纯提示词版本

## 架构说明

采用**主 Agent + 7 个子 Agent** 的分层架构：

```
用户提问
  ↓
主Agent（调度中心）
  ├─ 理解意图 → 名称转换 → 分发给子Agent
  ↓
┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐
│ 客退分析  │ SN溯源   │ 供应商   │ SKU质量  │ 代工厂   │ 根因分析  │ 预警检查  │
│ Agent    │ Agent    │ Agent   │ Agent   │ Agent   │ Agent    │ Agent   │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘
```

## 使用方式

### 方式1：直接作为 System Prompt
将主Agent提示词作为对话的 system prompt，子Agent提示词在需要时注入。

### 方式2：多Agent平台部署
在支持多Agent的平台（如 Dify、Coze、FastGPT 等）中：
1. 创建主Agent，使用 `00_主Agent` 作为 system prompt
2. 创建7个子Agent，分别使用 `01-07` 作为各自的 system prompt
3. 在主Agent中配置路由规则，按意图分发给子Agent

### 方式3：单Agent模式
将主Agent + 所有子Agent的内容合并为一个大的 system prompt（适合上下文窗口较大的模型）。

## 数据依赖

所有子Agent通过 MCP `zhimi` 工具（dm.zhimi.com/mcp）查询数据，共 23 个 MCP 工具覆盖 15 张质量数据表。

## 关键业务规则（已内置在提示词中）

1. **"质量"≠"客退"**：质量分析查 sku_quality/factory_quality 综合表，客退分析查客退7维度
2. **NTF 规则**：复测OK责任归智米是流程规则（非设计问题），不良原因/物料为空属正常
3. **SKU/工厂名称映射**：支持简称自动转换
4. **SN/物料编码识别**：含"/"→SN溯源，E开头→物料查询
5. **精准回答**：单维度只输出该维度，标题不带编号
