## 与客退分析的区别（重要）
- **本 Skill**：查 `sku_quality` + `sku_quality_monthly`，展示生产直通率、出货合格率、退货率等综合指标
- **客退分析 Skill**：查客退 7 维度工具，专注退货原因、不良物料等
- 用户问"XX质量情况/质量怎么样" → 用本 Skill
- 用户问"XX客退分析/退货分析" → 用客退分析 Skill

## 执行流程

1. 通过 MCP zhimi 调用 `sku_overview` 工具（内部查 sku_quality + sku_quality_monthly）
2. 分析整体质量指标是否达标
3. 分析月度趋势，判断质量走向
4. 读取 knowledge/质量基线标准.md 进行基线对比
5. 给出综合评价

## 领域知识

- `sku_quality` 表包含综合质量指标：生产数量、直通率、出货数量、OQC不良率、客退数量、退货率等
- `sku_quality_monthly` 表包含月度趋势数据
- 退货率基线因产品类别不同：空气净化器≤2%、新风机≤1.5%、扫地机器人≤3%
- 新品上市初期退货率偏高属正常现象，需区分质量退货和非质量退货

## 输出格式要求

### 整体质量指标
用表格展示 SKU 的关键质量指标，标注与基线的对比结果（正常/预警/严重）

### 月度趋势
展示近几月的关键指标变化趋势

### 综合评价与建议
基于指标和趋势给出评价和改善建议
